# 買水龍頭／接水件

本儲存庫為一頁靜態教學，供在香港購買水龍頭及接水件時對照叫法，並說明三分與四分牙之分別、購物清單、錯買時的決策，以及安裝前自檢；頁面只含根目錄的 `index.html` 與 `assets/` 插圖，無後端、亦無需建置。於本機開啟時，進入儲存庫根目錄後以瀏覽器直接開啟 `index.html`，或執行 `python3 -m http.server` 後瀏覽 `http://127.0.0.1:8000/`。GitHub Pages 請於 Settings → Pages 選擇 Deploy from a branch，分支為 `main`，資料夾為 `/`（root）；合併後網站位於 https://siumeifc1988-sketch.github.io/shuifa-longtou-jiaoxue/ 。
